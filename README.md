# 🌊 S.A.C. Windsurfing Club Website

A stunning, dynamic, and visually captivating website for the Student Activity Council (S.A.C.) Windsurfing Club. Built with modern web technologies and featuring brilliant dynamic visuals, seamless transitions, and an oceanic design aesthetic.

## ✨ Features

### 🎨 Design & Visual Effects
- **Oceanic Color Palette**: Deep ocean blues, electric turquoise, and safety orange accents
- **Modern Typography**: Inter font family with multiple weights for optimal readability
- **Dynamic Hero Section**: Full-screen video background with animated overlays
- **Parallax Scrolling**: Advanced scroll-triggered animations and transitions
- **Interactive Elements**: Hover effects, 3D transforms, and smooth state changes

### 🚀 Dynamic Interactions
- **Scroll Animations**: Elements "sail" and "pop" into view with wave-like motion
- **Animated Counters**: Statistics animate when scrolled into view
- **Event Cards**: 3D hover effects with rotation and scaling
- **Navigation**: Smooth sticky header with liquid mobile menu transitions
- **Contact Form**: Floating labels and interactive submission states

### 📱 Responsive Design
- **Mobile-First**: Optimized for all screen sizes
- **Touch-Friendly**: Enhanced mobile interactions
- **Performance**: Optimized loading and smooth 60fps animations

## 🏗️ Project Structure

```
SAC/
```

## 🔧 Customization

### Updating Content
- **Images**: Replace image URLs in `index.html` with your own
- **Text**: Update content directly in the HTML
- **Colors**: Modify CSS custom properties in `:root`
- **Animations**: Adjust timing and effects in `styles.css`

### Adding New Sections
1. Add HTML structure following existing patterns
2. Create corresponding CSS classes
3. Add JavaScript for any dynamic behavior
4. Update navigation links

## 🎯 Performance Features

- **Optimized Images**: Responsive images with proper sizing
- **Lazy Loading**: Images load as needed
- **Throttled Scroll Events**: Smooth 60fps performance
- **CSS Animations**: Hardware-accelerated transforms
- **Minimal Dependencies**: Lightweight and fast loading
